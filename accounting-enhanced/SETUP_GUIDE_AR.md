# دليل الإعداد والتشغيل 🚀

## ✅ تم بناء النسخة المحسّنة بنجاح!

لقد تم إنشاء **نسخة محسّنة وكاملة** من منصة المحاكاة المحاسبية مع التحسينات الـ 5 الأساسية.

---

## 📦 ما تم تضمينه

### ✨ التحسينات الـ 5 المطبقة:

#### 1️⃣ **Dark Mode** 🌙
- تبديل سلس بين المظهر الفاتح والداكن
- يتم حفظ التفضيل تلقائياً
- موجود في رأس الصفحة

#### 2️⃣ **نظام الإنجازات** 🏆
- 5 إنجازات مختلفة
- تتبع التقدم والشريط الحالي
- عرض شامل لكل إنجاز
- صفحة مخصصة للإنجازات

#### 3️⃣ **شروحات ذكية للأخطاء** 💡
- 8 أنواع مختلفة من الأخطاء
- شرح مفصل لكل خطأ
- نصائح عملية وأمثلة
- يمكن طلب تلميحات أثناء الحل

#### 4️⃣ **سيناريوهات متعددة** 🎲
- شركة تجارية (متجر ملابس)
- شركة خدمات (استشارات)
- شركة صناعية (مصنع غذائي)
- اختيار عشوائي في كل جلسة

#### 5️⃣ **شهادات احترافية** 🎓
- شهادة مصممة بشكل احترافي
- معرف فريد لكل شهادة
- معدل النجاح والإحصائيات
- قابلة للتحميل والمشاركة

## 💻 التثبيت على جهازك المحلي

### المتطلبات:
- Node.js 16 أو أحدث
- npm أو yarn

### الخطوات:

```bash
# 1. انتقل للمجلد
cd accounting-enhanced

# 2. ثبّت المكتبات
npm install

# 3. شغّل الخادم المحلي
npm run dev

# 4. افتح المتصفح وادخل:
# http://localhost:5173
```

## 🎨 تخصيص المنصة

### تغيير الألوان:
عدّل `tailwind.config.ts`:
```typescript
primary: {
  DEFAULT: 'hsl(221 83% 53%)', // الأزرق الحالي
}
```

### إضافة سيناريوهات جديدة:
عدّل `src/data/scenarios.ts` وأضف سيناريو جديد

### تغيير الشروحات:
عدّل `src/data/hints.ts` وأضف شروحات جديدة

---

## 📊 كيفية عمل النظام

### تدفق المستخدم:
```
الرئيسية → اختيار المحاكاة → اختيار المرحلة 
  → إدخال البيانات → التحقق → النتيجة
  → المرحلة التالية → ... → الشهادة
```

### حفظ البيانات:
- كل شيء محفوظ في `localStorage`
- لا توجد بيانات على الخادم
- الخصوصية الكاملة

## 🔧 المشاكل الشائعة والحلول

### المشكلة: `npm install` بطيء
**الحل:** استخدم `npm ci` بدلاً من `npm install`

### المشكلة: المنفذ 5173 مشغول
**الحل:** غيّر المنفذ في `vite.config.ts`

### المشكلة: الشهادة لا تحمّل
**الحل:** تأكد من أن اسم المستخدم مدخل بشكل صحيح
