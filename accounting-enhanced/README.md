# منصة المحاكاة المحاسبية 📊

نسخة محسّنة وحديثة من منصة تعليمية لتعليم المحاسبة بالممارسة العملية من خلال محاكاة تفاعلية.

## ✨ الميزات الرئيسية

### 1. 🌙 Dark Mode (المظهر الليلي)
- تبديل سلس بين المظهر الفاتح والداكن
- توفير الطاقة والراحة البصرية
- الحفظ التلقائي للتفضيل

### 2. 🏆 نظام الإنجازات (Achievement System)
- 5 إنجازات مختلفة
- تتبع الشريط الحالي (Streak)
- عرض شامل لجميع الإنجازات
- تاريخ فتح كل إنجاز

### 3. 💡 شروحات ذكية للأخطاء (Smart Error Hints)
- تلميحات مخصصة لكل خطأ
- شرح مفصل للمشاكل
- أمثلة عملية
- نصائح بناءة

### 4. 🎲 سيناريوهات متعددة (Multiple Scenarios)
- شركة تجارية
- شركة خدمات
- شركة صناعية
- اختيار عشوائي في كل جلسة

### 5. 🎓 شهادة احترافية (Professional Certificate)
- شهادة مصممة بشكل احترافي
- معرف فريد لكل شهادة
- معدل النجاح والإحصائيات
- إمكانية التحميل والمشاركة

## 🏗️ البنية التقنية

### التقنيات المستخدمة
- **Frontend:** React 18 + TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **State Management:** Zustand + Context API
- **Routing:** React Router v6
- **Icons:** Lucide React
- **PDF Generation:** jsPDF + html2canvas

### البنية الأساسية
```
src/
├── components/           # المكونات القابلة لإعادة الاستخدام
│   ├── Header.tsx       # رأس الصفحة مع تبديل المظهر
│   └── CompletionCertificate.tsx  # عرض الشهادة
├── contexts/            # إدارة الحالة العامة
│   ├── ThemeContext.tsx
│   └── AchievementsContext.tsx
├── pages/              # الصفحات الرئيسية
│   ├── HomePage.tsx    # الصفحة الرئيسية
│   ├── SimulationPage.tsx  # محاكاة الدورة المحاسبية
│   └── AchievementsPage.tsx # عرض الإنجازات
├── data/              # البيانات الثابتة
│   ├── scenarios.ts    # السيناريوهات
│   └── hints.ts        # الشروحات الذكية
└── utils/             # الدوال المساعدة
    └── certificateGenerator.ts
```

## 🚀 البدء السريع

### المتطلبات
- Node.js 16+
- npm أو yarn

### التثبيت والتشغيل

```bash
# استنساخ المستودع (أو تنزيل الملفات)
git clone <repo-url>
cd accounting-enhanced

# تثبيت المكتبات
npm install

# تشغيل بيئة التطوير
npm run dev

# بناء للإنتاج
npm run build

# معاينة النسخة المبنية
npm run preview
```
